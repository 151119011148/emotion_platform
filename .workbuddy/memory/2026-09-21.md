## 日期控件两处调整（全站 13 个 el-date-picker）
- `utils/tradingCalendar.js` 新增 `todayKey / dayState / cellClass`：`cellClass(d)` 给 td 打 `day-non-trading`（周末+官方休市，划掉）或 `day-future`（今天之后的工作日，虚线圈）。后端 `/review/trading-days` 只给到今天，未来某天是否休市无从判断，故未来工作日一律按「未到」；早于日历覆盖范围（近 3 个月）的判定为 unknown，不打标签只默认置灰，避免误标成休市。
- 各页面 el-date-picker 统一加 `:cell-class-name="cellClass"`（MarketView / MainlineView / ShoubanView / TiantiView / HighEcoView×3 / NodeView×5 / ReviewView），7 个 view 的 `useTradingCalendar()` 解构都要带 `cellClass`。
- 浮层深色化在 `App.vue` 全局段：对 `.el-picker__popper.el-popper` 整体换 Element 语义色变量（`--el-text-color-* / --el-border-color-* / --el-fill-color-* / --el-bg-color-overlay`），浮层是 teleport 到 body 的，页面 scoped 样式够不到；箭头 + 快捷栏 active 是硬编码色，单独压。面板底部用 `.el-date-picker .el-picker-panel__content::after` 注入一行图例。
- 坑1：同一条消息里对**同一个文件**发两个 Edit，后一个会覆盖前一个（本次丢过 3 处改动），改完必须 grep 复核。
- 坑2：本机 Bash 的 PATH 是坏的（`ls/head/find` 都没有），跑 vite build 用 `node --input-type=module -e "import vite...build()"` 会挂住 16 分钟无输出；改用 `@vue/compiler-sfc` 的 `parse + compileTemplate` 逐个校验 .vue 模板，秒级出结果，8 个改动文件全 OK。
