  2. **题材板块表** —— 每个题材/概念板块下包含的个股清单

## 文件清单与用途

### 1. `tdxhy.cfg`（150,440 字节）
- 原始路径：`T0002\hq_cache\tdxhy.cfg`
- 作用：**个股 → 行业分类归属表**，是生成二级行业分类表的主数据。
- 格式：纯文本，每行一条记录，字段以 `|` 分隔：

  ```
  市场|股票代码|通达信行业码|||证监会行业码
  0|000001|T1001|||X500102
  0|000002|T110201|||X530101
  ```

- 字段说明：
  - 市场：`0` = 深圳/北交所，`1` = 上海
  - 通达信行业码：**按长度区分层级**
    - `T01` 长度 T+2 位 → 一级行业（门类）
    - `T0101` 长度 T+4 位 → **二级行业（本次导出目标）**
    - `T010101` 长度 T+6 位 → 三级行业（细分）
- 解析要点：取行业码前 5 个字符（即 `T` + 4 位数字）即可得到该股所属**二级行业代码**，再按二级行业分组汇总个股。

---

### 2. `incon.dat`（67,543 字节）
- 原始路径：根目录 `incon.dat`
- 作用：**各种行业分类体系的“代码 → 名称”对照表**，用于把 `tdxhy.cfg` 里的行业码翻译成中文名称。
- 格式：GBK 纯文本，按段落组织，段落以 `#` 开头：

  ```
  #ZJHHY      → 证监会行业分类
  #TDXNHY     → 通达信行业分类（本次要用的一段）
  #SWHY       → 申万行业分类
  #ZXHY       → 中信行业分类
  #CJHY       → 长江行业分类
  #ZZHY       → 中证行业分类
  #HKHY/#MGHY/#SGXHY → 港股/美股/新交所行业
  ...
  ```

  段落内每行格式为 `代码|名称`，例如（`#TDXNHY` 段）：

  ```
  T01|能源
  T0101|煤炭
  T010101|煤炭开采
  T02|材料
  T0201|钢铁
  ```

- 解析要点：只需抽取 `#TDXNHY` 段，建立 `{行业码: 行业名称}` 映射；二级行业取长度为 `T`+4 位的行。

---

### 3. `infoharbor_block.dat`（742,711 字节）
- 原始路径：`T0002\hq_cache\infoharbor_block.dat`
- 作用：**板块成分股库**，是生成题材板块表的主数据。通达信新版已不再使用经典的 `block_gn.dat` / `block_zs.dat`，题材板块成分实际存放在此文件。
- 格式：GBK 纯文本，一个板块 = 「一行块头」+「若干行成分股」：

  ```
  #GN_通达信88,88,880515,20050607,20260512,,
  0#000408,0#000538,0#000708,0#000792,0#000895,...
  0#300033,0#300059,0#300124,...
  ```

- 字段说明：
  - 块头：`#` + 前缀 + `_名称` , 简称 , 板块指数代码 , 基日 , 更新日期 , 空 , 空
    - 前缀含义（待全量校验）：`GN_` = 概念/题材板块，`ZS_` = 指数板块，`FG_` = 风格板块，`HY_` = 行业板块
  - 成分股行：`市场#股票代码`，多个之间用逗号分隔；市场 `0` = 深圳/北交所，`1` = 上海
- 解析要点：以 `#` 开头的行切分为新板块，后续非 `#` 行的全部代码归为该板块成分股。

---

### 4. `tdxbk.cfg`（1,451 字节）
- 原始路径：`T0002\hq_cache\tdxbk.cfg`
- 作用：**终端界面上显示的板块名单**（题材/概念、风格、指数类的板块简称与全称对照），可作为题材板块表的**名称索引与分类标签**。
- 格式：`类别|板块简称|板块全称|标记`

  ```
  1|锂电池|锂电池概念|0
  1|人形机器|人形机器人|0
  2|沪港通SH|沪股通标的|1
  3|MSCIA50|MSCI中国A50|0
  ```

- 字段说明：类别 `1` = 概念/题材板块，`2` = 风格与特色板块，`3` = 指数类板块；末位标记为展示开关（`0`/`1`）。

---

### 5. `spblock.dat`（316,972 字节）
- 原始路径：`T0002\hq_cache\spblock.dat`
- 作用：**特殊板块成分股**（如融资融券标的等），可与题材板块表做交叉标注，例如标记成分股是否属于两融标的。
- 格式：GBK 纯文本，块头为 `#板块名`，其后每行为一个 7 位股票代码：

  ```
  #融资融券
  0000001
  0000002
  0000006
  ```

- 解析要点：代码为 7 位（市场位 + 6 位代码，首位 `0` = 深/北，`1` = 沪），需去掉首位市场位后再与个股代码对齐。

---

### 6. `base.dbf`（3,957,058 字节）
- 原始路径：`T0002\hq_cache\base.dbf`
- 作用：**全市场证券基础资料库（DBF 数据库文件）**，提供股票代码 → 股票名称、上市日期、总股本等基础字段，用于把导出表中的代码翻译成中文简称。
- 格式：标准 dBASE III/IV（DBF），需按 DBF 头解析字段描述区后逐条读取记录（可用 Python `dbfread` / `simpledbf`，或手写 struct 解析）。
- 配套索引：`base.map`（119,250 字节，未打包，仅作定位索引）。

---

### 7. `code2name.ini`（13,182 字节）
- 原始路径：`T0002\hq_cache\code2name.ini`
- 作用：**代码 → 名称的轻量对照表**（覆盖部分特殊代码、指数与板块代码）。`base.dbf` 解析不便时的备选名称来源。
- 格式：INI/文本，形如 `代码=名称` 或 `名称,代码` 的键值对，读取后可直接建映射。

## 建议的解析流程

1. 读 `incon.dat` 的 `#TDXNHY` 段 → 建立行业码→名称映射（含一级/二级/三级）。
2. 读 `tdxhy.cfg` → 逐行取通达信行业码，截取 `T`+4 位得到**二级行业码**，按二级行业聚合个股（市场 0/1 + 6 位代码）。
3. 用 `base.dbf`（或 `code2name.ini`）把股票代码补全为名称 → 输出 **《二级行业分类表》**。
4. 读 `infoharbor_block.dat` → 以 `#` 行切块，抽取 `GN_` 前缀（题材/概念）板块及其成分股 → 输出 **《题材板块表》**。
5. 可选：用 `tdxbk.cfg` 补齐板块全称与类别标签；用 `spblock.dat` 标注两融等特殊属性。
