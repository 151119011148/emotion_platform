空间破局节点（space_break）专项 PRD

把「全市场连板天花板被打开 / 被压制」这件事单独建成第四类节点。 破局日 = 空间板断板日 = 观察日（0 候选）； 破局次日 = 修复日 = 出手日（产出候选池）。 本文是主 PRD《短线连板周期选股策略引擎》v1.2 §5 节点体系的扩展，全部阈值已在 19 个交易日真实数据上标定。

0 · 定位与改动清单

一句话
横向看周期、纵向看高度：启动 / 分歧 / 切换三类周期节点回答「情绪走到第几拍、资金往哪个方向去」； 空间破局这一族空间节点回答「连板天花板在哪、是否被压制」——它描述的不是第三种情绪状态，而是一个独立于题材的高度事件， 所以既不能被切换日吸收，也不该被分歧日吸收，必须单独建一类。

1 · 为什么必须单独建一类

1.1 三类现有节点的盲区

节点它回答的问题它回答不了的问题
启动日情绪是不是从冰点转暖（涨停家数爆发）情绪转暖但高度没打开——一堆首板、没有连板梯队，第二天照样一日游
分歧日高位股是不是失去赚钱效应（炸板潮）分歧之后谁来接高度——它只报警，不给新龙头
切换日资金是不是换了题材（新题材爆发 + 旧主线熄火）题材换了但高度还是原来的那个高度——换了方向没换空间，是横移不是破局
空间破局新增全市场的连板天花板在哪、什么时候被打开、打开后谁是新的高度载体
关键区分：破的是「高度」，不是「题材」，也不是「情绪」
  • 切换日可以高度不变：4 板换到另一个 4 板，题材换了、空间没换 → 这是横移，不是破局。
  • 分歧日可以高度还在：高位股炸板但空间板自己还封着 → 分歧不等于破局。
  • 启动日可以高度很低：涨停 93 家但最高板才 6 板、且是老龙续命 → 启动不等于破局。

1.2 破局节点解决的真实问题

周期里最关键的两次决策，恰好都落在「高度」上：

  1. 什么时候停手：空间板断板 = 天花板被压制，当天无论涨停多少家都是「高度的真空期」，不应该出手。
  2. 什么时候换龙头：断板次日的修复日 = 新龙头诞生日，这是唯一值得重仓的节点。

这两件事现有三类节点都不负责，所以必须单独建。

1.3 非目标（明确边界）

  • 不做高度预测：不预测明天会不会破 6 板，只识别「今天的空间板是不是断了」。
  • 不替代身位板原则：破局节点只决定「今天是不是出手日 + 打几折」，具体买谁仍由 §4 同题材身位板原则决定。
  • 不做盘中实时判定：破局日/破局次日均为收盘后判定，产出的是次日开盘前的候选池（与主 PRD §8.1 触发时机一致）。
  • 不写死任何个股或题材：闽东、电力、福建仅作叙述示例。

周期节点phase_node统称，非 node_type 取值。指启动 / 分歧 / 切换三类，回答「周期走到第几拍、资金流向哪个方向」，属横向维度；三类之间可同日并存—
空间节点space_node统称，非 node_type 取值。指破局日 / 破局次日两类，回答「全市场连板天花板的位置」，属纵向维度—

与主 PRD §2 已有术语（身位板 / 节点票 / 炸板率 / 一字板 / 换手板等）共用同一套口径，不另作解释。

命名约定：禁止用「普通 / 常规 / 其他节点」指代非破局节点
「普通、常规、其他」都是反义定义——只说明它不是什么，不说明它是什么； 而且每新增一个 node_type，这个词的含义就要跟着变一次，属于长期的口径债务。

本 PRD 统一按两个正交的轴描述节点：
· 来源轴（这张节点从哪来）：人工节点 落 t_node_event、策略节点 落 t_node_detect，两套互不写入，不要混为一谈。
· 类型轴（它是什么）：五个具体 node_type。策略没识别出来的就是 null，UI 显示「未识别」，绝不回填「普通」。

确实需要统称时，用 axis 而不是 negation：周期节点 phase node（启动 / 分歧 / 切换） vs 空间节点 space node（破局日 / 破局次日）。

3 · 破局日（观察日）

定义（务必按此实现）
破局日 = 空间板断板日。不是「突破前高那天」，也不是「连板数创新高那天」。 它是高度被压制的日子，因此是观察日：不产生任何候选、不建仓。

3.1 三个子条件（全部满足才标破局日）

条件判据默认值与说明
C1 前一交易日存在唯一空间板 S，且 S.board ≥ min_space_board min_space_board = 5。并列最高板不算空间板（F16）。低于 5 板的「高度」不构成天花板，断了也不叫破局（样本内 09-10 桂林旅游 4 板断、09-11 瑞尔特 4 板断、09-14 闽东 4 板继续，均不触发）
C2 S 在 T 日断板（T 日未收盘涨停） 断板形态三分，见 §3.2。其中「A 杀」形态直接否决破局日——那是退潮，不是破局
C3 当日情绪没有崩塌（三个软条件同时满足） 涨停家数 ≥ zt_floor(40) 且 跌停家数 ≤ dt_limit(10) 且 炸板率 ≤ zb_rate_limit(45%)。
三者任一不满足 → 当日是退潮日而不是破局日，标 RETREAT
为什么三个子条件都在描述「断板」
因为破局这件事的本质就是高度断点：C1 保证断的那个真的是天花板（不是随便一只 4 板）， C2 保证确实断了（不是还在封），C3 保证这个断不是崩塌式断（否则是退潮，出手逻辑完全不同）。 三条缺一，断板就失去意义。

3.2 断板形态三分（决定 C2 是否成立）

形态判据是否破局日含义
A 杀收盘跌停（落入 DT 池），或跌幅 ≤ a_kill_limit(-7%)否核按钮 / 末日轮。这是退潮，走主 PRD 退潮期模板，不走破局逻辑
炸板断板盘中触及涨停但收盘未封住（落入 ZB 池）是高度当日冲高被压制，是最典型的破局形态
温和断板收盘未涨停、未跌停，且未触及涨停（当日三池均无该股）是高位横住 / 小阴，良性破局，次日修复概率最高

判据按池归属即可判定，无需额外取涨跌幅：DT 池 = A 杀，ZB 池 = 炸板断板，三池均无 = 温和断板。 若已接入日 K（t_daily_bar），可用 chg ≤ a_kill_limit 兜底复核（F19）。

3.3 三种破局日的盘面形态

良性破局

形态：空间板温和断板 / 小阴，跌停极少，涨停家数不塌

处置：标准破局日，次日正常进入修复判定

炸板破局

形态：空间板盘中封板被砸开，炸板率抬升但跌停仍少

处置：仍是破局日，但次日修复判定加严一档（要求炸板率必须下降）

A 杀（不标破局）

形态：空间板跌停，或跌停家数 > 10、涨停腰斩

处置：判为退潮日，标 RETREAT，走退潮期模板

3.5 破局日当天：出手还是不出手

明确规则：破局日不出手，候选池恒为 0
  • 破局日不产生任何候选，t_candidate_stock 当日 0 行，运行记录 status=EMPTY, warning=SPACE_BREAK_OBSERVE。
  • 理由：空间板断板当天是高度真空期——老龙已死、新龙未定，当天所有涨停都只是「情绪余温」， 次日大概率被新龙头吸走资金。当天买 = 买在高度最不确定的一天。
  • 但节点必须打标并落 t_node_detect(node_type='SPACE_BREAK')，因为它是破局次日的前置锚。

这条与主 PRD §5.4「节点票筛选」不冲突：破局日是节点但不产票，是四类节点里唯一的一类。

4 · 破局次日（出手日）

定义
破局次日 = 破局日的下一交易日 = 修复日 / 新龙头诞生日。 这是破局节点体系里唯一产出候选池的日子。但它不是自动成立——必须先判定「修复成功」。

4.1 修复判定（三个条件全部满足）

条件判据默认值与说明
R1破局股 S 在次日未 A 杀次日未跌停（DT 池无 S）。若 S 次日跌停 → 断板延续为 A 杀，修复失败
R2情绪宽度未腰斩且炸板率未恶化zt(D) ≥ zt(T) × 0.8 且 zbr(D) ≤ zbr(T) + 5pp
R3存在承接身位当日最高板 ≥ 3 板，且存在 3~5 板区间的收盘涨停股 ≥ 1 只

三条任一不满足 → 标记 repair_failed，当日降级为观察日，不产候选，并在 t_node_detect.hit_expr 注明失败的具体条件。

5 · 破局次日的四档选法

L1
身位承接
全市场唯一最高身位，且处于 3~5 板区间 · 换手优于纯一字 · 首选，只买一只
L2
身位跟随
2 板及以上、非最高身位 · 只在 L1 一字买不到 / L1 为空时取，每题材 ≤1 只
L3
新支线独立首板
首板 + 该题材当日涨停 ≥3 只 + 昨日该题材 ≤1 只 + 题材内首封最早 · 用于试错新周期
L4
独立无板块首板
首板但所属题材当日涨停 < 3 只 · 默认过滤，不入候选（可配置为观察标签）

5.1 L1 身位承接（最优先）

  • 选取：破局次日收盘涨停池中，连板数 = 当日全市场最高，且 3 ≤ board ≤ max_successor_board(5)。
  • 唯一性：最高身位并列 ≥2 只时，按 position_mode（默认 highest_board → first_seal_time 早者优先）取 1 只；其余不降级进 L2，直接放弃（F17）。
  • 为什么封顶 5 板：破局次日若最高身位已 ≥6 板，说明高度不是新打开的，而是老龙续命（真实样例：08-27 最高板为深中华A 6 板，是从 08-26 的 5 板续上来的，不是新龙头）→ 该情况 L1 应为空，见 §5.5。
  • 质量偏好：换手板 > 一字板（一字板无法在次日竞价成交，按主 PRD §6.2 一字缩量风险扣分）。
  • 同题材约束：承接身位若与破局股同题材，额外加权（破局属性继承）；若不同题材，视为「换方向接高度」，正常计分但不加权。

5.2 L2 身位跟随（次优先，有前提）

  • 前提：只有以下两种情况才启用 L2 —— ① L1 为一字板（买不进）；② L1 为空（最高身位 > 5 板）。
  • 选取：2 ≤ board < 当日最高板 的收盘涨停股，按题材分组各取首封最早的 1 只（复用主 PRD node_stock_limit_per_theme = 1）。
  • 排序：连板数降序 → 首封时间升序 → 封单/成交额降序（方向依据主 PRD §12.4.5）。

5.3 L3 新支线独立首板（试错档）

  • 选取：首板（board = 1）且 该题材当日涨停 ≥ new_theme_min_zt(3) 且 该题材昨日涨停 ≤ 1（新支线）且 该题材内首封时间最早。
  • 排除：ST / 上市 < filter_new_stock_days 天 / 成交额 < filter_min_amount(0.5亿)（主 PRD 过滤器复用）。
  • 用途：破局次日资金从老方向外溢到新方向，这批票是「新周期的第一批票」，赔率高但胜率低，只给半仓。

5.4 L4 独立无板块首板（默认过滤）

  • 首板且所属题材当日涨停 < 3 只 → 不入候选池，可写 t_candidate_stock.filter_detail_json 的 EXCLUDED_L4 明细。
  • 理由：无板块效应的首板在破局次日是「情绪随涨」，次日大概率一日游。

6 · 买点与仓位

6.1 三个买点（破局次日专用）

买点触发适用档位仓位
竞价买承接身位（L1）高开 2%~5%、竞价额 > 阈值、且破局股未核按钮L10.7 × 上限
半路买L1 一字或高开 > 7% 不追 → 转买 L2 中首封最早的换手板L20.6 × 上限
扫板买L3 新支线首板首次封板瞬间，要求该题材已有 ≥3 只涨停L30.5 × 上限

破局日（T）三个买点全部禁用——观察日不建仓。

6.2 仓位规则

单票仓位 = min(max_position_per_stock × break_position_scale, break_max_single_position) 组合上限 = break_day_max_total （破局日 = 0，破局次日 = 30%） break_position_scale = 0.7 破局节点整体折扣（高标刚打开，后排易一日游） break_max_single_position = 0.03 破局节点单票硬上限（低于主 PRD 全局 5%） break_day_max_total = 0.30 破局次日单日总仓上限
为什么破局节点的仓位比切换日低一档
破局次日的高度是刚被重新打开的，后排票的确定性远低于「已经走了三天的成熟主线」： 新龙头可能次日就断，跟随票大概率一日游。因此单票 3%（低于全局 5%）、总仓 30%， 避免「在最不确定的一天上最重的仓位」。

6.3 破局股次日校验（T+2 的降权开关）

  • 破局股 S 在破局次日红盘 / 炸板未跌停 → 正常持有，L1 可考虑 1 进 2。
  • 破局股 S 在破局次日跌停 / 跌幅 ≤ -7% → 触发 BREAK_STOCK_DEAD： 当日全部破局候选降权 50%，并在复盘面板标红（F20）。
  • 真实样例：闽东电力 09-17 温和断板，09-18 落入炸板池（未跌停）→ 未触发降权，09-18 候选正常发放。

7 · 与其他节点的互斥与优先级

7.1 破局日 vs 分歧日

分歧日

判据是高位股整体失去赚钱效应（昨日 ≥3 板个股今日平均涨幅 < 0 + 炸板率 > 25%）。它报警，但不指明谁接棒。

破局日

判据是唯一最高空间板断板。它是分歧的一个具体后果，但也可能在情绪不分歧时发生（老龙自然退位）。

关系：相交但互不包含。样本内破局日 5 天中有 3 天（08-26 / 09-08 / 09-17）同时满足分歧日的近似口径（炸板率 > 25%）， 但分歧日的正式判据（需 t_zt_perf）只命中 09-14，与破局日零重叠。 因此规则定为：两者可同日并存，分别落 t_node_detect，不互斥；但破局日优先级更高（它是可执行的高度事件，分歧日只是风险提示）。

7.2 破局日 vs 分支切换日

切换日的本质是「方向换了」，破局日的本质是「高度断了」。可同时发生（09-08 既是破局日又是切换日）： 龙版传媒 6 板断板的同时有新的成规模题材崛起。此时 按破局日处理： 当日仍是观察日（0 候选），切换日的候选顺延到破局次日一起产出。

判定口诀
换了方向但高度没断 → 切换日（可以出手）；高度断了无论换不换方向 → 破局日（不出手）。

7.3 破局日 vs 冰点启动日

启动日是「涨停家数从地量爆发」，破局日是「空间板断板」，两者触发方向相反： 启动日要求今日涨停数 > 昨日 × 1.5（放大），而破局日往往伴随涨停数的回落。 样本内 09-18 同时命中两者（涨停 47→78 放大 + 澳弘电子 5 板断板）， 属于「断板但情绪反而爆发」的罕见组合，规则定为按启动日处理候选、但仓位仍按破局折扣—— 即情绪支持出手，但高度不确定要求降仓。

7.4 权重表与优先级（唯一权威口径）

节点类型权重产出候选单票上限说明
冰点启动日 start1.0是5%最高优先级：情绪与高度同时转好
破局次日 space_break_next0.9是3%新龙头诞生日，唯一按四档选法的日子
分支切换日 switch0.8是5%方向换了但高度未打开
分歧日 diverge0.6是5%风险提示型节点
破局日 space_break—否（0 候选）0%观察日，仅打标作为破局次日的前置锚

互斥规则（三条，按顺序判定）

  1. 同位不叠加：同一交易日同时是「破局日」和「另一破局日的破局次日」时（真实样例：09-18）， 破局日优先 → 当日判为观察日，0 候选；破局次日的候选顺延不补发（F18）。
  2. 同日多节点取最高权重：破局次日与切换日同位时（真实样例：08-27、09-21）， 按 space_break_next(0.9) > switch(0.8) 取破局次日的四档选法，切换日候选并入 L3 档参与排序，不重复计分（复用主 PRD F3）。
  3. 破局日与分歧日/切换日/启动日同位：全部落 t_node_detect，secondary_nodes 记录， 但候选产出与否只看「当天是不是破局日」——是则 0 候选。

7.5 真实交叉矩阵

集合日期处置
破局日 ∩ 切换日2026-09-08按破局日 → 0 候选，切换日候选顺延
破局日 ∩ 启动日2026-09-18同位冲突 → 按破局日（规则 1）→ 0 候选
破局日 ∩ 分歧日（近似口径）08-26 / 09-08 / 09-17不互斥，两者都打标；候选仍由破局日规则决定
破局次日 ∩ 切换日2026-08-27 / 2026-09-21取破局次日（0.9 > 0.8），切换日候选并入 L3
破局日 ∩ 破局次日（同位）2026-09-18规则 1：破局日优先 → 观察日，0 候选
09-18 是最值得记住的边界样例
09-17 闽东电力 6 板断板 → 09-18 是破局次日；但 09-18 当天澳弘电子 5 板也断了 → 09-18 同时又是新的破局日。 连续断板 = 高度连续被压制 = 退潮特征，此时绝不能按「新龙头诞生日」出手。 规则 1 明确规定：同位时破局日优先，当天 0 候选。

15 · 如何融入现有「节点追踪」页面

先说结论：结构同构，可以零侵入复用，不需要另起一个页面
现有节点追踪页（NodeView.vue / /nodes）的数据模型 t_node_event 本身就是「D0 → T+1 → 确认」的两日验证结构， 而破局节点天然也是两日：破局日（D0，观察）→ 破局次日（T+1，出手）。 两者是同构的，所以最省事的做法是把破局做成一种「节点类型」塞进现有页面， 而不是新建一个 WaveRider 页面。

15.2 两个「免费」的一致性（这是选择复用而非新建的关键理由）

一致性一：两日结构天然匹配

破局日 = D0、破局次日 = T+1，直接对应现有 d0_date / t1_date。 破局日的「0 候选」= d0_candidates 为空；破局次日的四档候选 = 复算时按明细现算（与 NodeSuggestService 「不用手打候选、按盘面明细复算」的既有约定完全一致）。

一致性二：现有过滤器已经会拦住破局日

现有过滤器第 4 条是「连板高度未连续压缩 3 天」（HEIGHT_COMPRESS_DAYS=3）。 破局日恰恰就是高度被压缩的那天 → filter_passed = 0。 「破局日不出手」这条规则，现有过滤器免费实现了，不需要写新逻辑。

反过来验证：三个成立的破局次日（08-27 涨停 77、09-18 涨停 78、09-21 涨停 103） 全部 > 60，都能通过现有 MIN_LIMIT_UP； 而三个破局日（08-26 涨停 52、09-02 涨停 52、09-08 涨停 73） 中两个不过 60、且全部处于高度压缩状态 → 被自然拦下。两条阈值体系不冲突，反而互相印证。

15.6 不建议做的事

  • 不建议新建独立页面：破局节点在盘面上就是节点的一种，单独开页会导致用户要在两个地方看节点，且 D0/T+1 状态机要重写一遍。
  • 不建议现在建 t_strategy / t_node_detect / t_candidate_stock 七张表：那是 WaveRider 完整策略引擎的事（V29），破局节点只需要 t_node_event 加 5 列就能跑起来。把两件事解耦，破局可以独立先上线。
  • 不建议改现有前置过滤器阈值：现有 4 条过滤器已经在生产上跑，且恰好能表达「破局日不出手」。新增逻辑应该并列而非修改。
