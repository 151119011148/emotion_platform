策略选股 · 得分明细设计预览

当前「得分」列只有一个总分，看不出分是怎么来的。下面三个方案都基于同一份公式： 得分 = 高度 0.5×(板数÷当日最高板) + 身位 0.3×(是否题材最高板) + 节点 0.2×(类型系数) + 早封 0.1×(是否10:00前) − 风险 0.2×(扣分，上限1)， 满分 1.10。示例数据权重取默认模板（0.5 / 0.3 / 0.2 / 0.1 / 0.2），当日最高板 = 5 板。 鼠标停在得分格上看明细（方案 A），点「明细」看展开行（方案 B）。

读法：色条按四项正贡献的比例切分，越靠左＝越靠前的因子；扣分项在右端用斜纹另画一段， 不跟正项混色（否则「分数高」会被读成「没扣分」）。悬浮面板给出 权重 × 原始值 = 得分 的完整算式与合计 / 满分，仓位那一行顺便说清「为什么它被折半」。 未评分的历史行退化为灰虚条 + “—”，不猜。
