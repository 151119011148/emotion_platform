## 一、文档概述

### 1.1 产品定位

本系统是一个**短线情绪量化评分 + 周期节点定位 + 题材生命周期管理 + 龙头分工定位 + 交易指令输出**的一体化工具。核心能力是将每日盘面数据转化为 **“5维评分 → 节点定位 → 主线/龙头状态 → 操作指令”** 的决策闭环，解决“温度有多热、周期在哪、钱落哪只票、该空仓还是满仓”四大问题。

### 1.2 核心目标

| 目标 | 说明 |
|:---|:---|
| 客观量化 | 0-100分5维评分，杜绝主观情绪干扰 |
| 结构透视 | 四层划分（低/中/中高/极高）识别资金流向 |
| 周期导航 | 六态节点状态机（冰点→启动→发酵→高潮→分歧→退潮） |
| 主线选股 | 题材5要素识别主线，生命周期判定持续性 |
| 龙头定位 | 总龙头/中军/跟风/卡位/反包分工评估阵眼强度 |
| 监管感知 | 异动监管池外挂修正，规避政策风险 |
| 交易落地 | 每日输出明确仓位、方向、禁区、明日锚点 |

### 1.3 核心概念速查

| 概念 | 定义 |
|:---|:---|
| 5维评分 | 大盘生态(25%)+主线明确度(20%)+连板生态(25%)+首板生态(15%)+阵眼(15%) |
| 主线5要素 | 涨停聚集度、高度聚集度、成交额聚集度、催化剂硬度、持续性 |
| 龙头分工 | 总龙头(温度计)、中军(容量)、跟风(强度)、卡位(分歧护盘)、反包(修复) |
| 题材生命周期 | 萌芽→确认→扩散→亢奋→退潮 |
| 四层划分 | 低位(2板)、中位(3-4板)、中高位(5~⌈H/2⌉)、极高位(⌈H/2⌉+1~H) |
| 节点 | 冰点/启动/发酵/高潮/分歧/退潮，六态状态机 |
| 监管修正 | R分(0-100)外挂层，通过反馈/密度/结构映射折扣 |

## 三、数据库设计

### 3.1 stock_base（股票主池）

```sql
CREATE TABLE stock_base (
    ts_code        VARCHAR(12) PRIMARY KEY,
    symbol         VARCHAR(10) NOT NULL,
    name           VARCHAR(32) NOT NULL,
    exchange       VARCHAR(8) NOT NULL,
    board          VARCHAR(16),
    industry       VARCHAR(32),
    is_st          BOOLEAN DEFAULT FALSE,
    is_new_stock   BOOLEAN DEFAULT FALSE,
    list_date      DATE,
    free_float     NUMERIC(16,2),
    total_float    NUMERIC(16,2),
    limit_pct      NUMERIC(5,2) DEFAULT 10.0,
    delisted       BOOLEAN DEFAULT FALSE,
    updated_at     TIMESTAMP DEFAULT NOW()
);
CREATE INDEX idx_stock_base_board ON stock_base(board);
```

### 3.2 concept_base（板块题材池）

CREATE TABLE concept_base (

## 四、后端引擎设计

### 4.1 评分计算引擎

```python
class SentimentEngine:
    WEIGHTS = {'market': 0.25, 'concept': 0.20, 'lianban': 0.25, 'shouban': 0.15, 'zhenyan': 0.15}
    
    def calc_daily(self, trade_date: str) -> dict:
        mkt = self._calc_market(trade_date)
        conc, conc_detail = self._calc_concept_detail(trade_date)  # 含5要素
        conc = self._apply_monitor_discount(conc, trade_date)
        lb = self._calc_lianban(trade_date)
        sb = self._calc_shouban(trade_date)
        zy, zy_detail = self._calc_zhenyan_detail(trade_date)      # 含龙头分工
        
        total = sum(self.WEIGHTS[k] * v for k, v in 
                    zip(self.WEIGHTS, [mkt, conc, lb, sb, zy]))
        force_exit, reason = self._check_force_exit(trade_date, lb)
        
        return {
            'total': round(total, 2),
            'details': {
                'market': mkt, 'concept': conc_detail, 
                'lianban': lb, 'shouban': sb, 'zhenyan': zy_detail
            },
            'force_exit': force_exit, 'force_reason': reason
        }
    
    def _calc_concept_detail(self, date) -> tuple:
        """主线20%拆为5要素"""
        # 1.涨停聚集度(25%) 2.高度聚集度(25%) 3.成交额聚集度(20%) 4.催化剂硬度(15%) 5.持续性(15%)
        ...
        return total, {'zt_ratio':.., 'height':.., 'amount':.., 'hardness':.., 'continuous':..}
    
    def _calc_zhenyan_detail(self, date) -> tuple:
        """阵眼15%拆为龙头分工"""
        # 总龙头(50%) + 中军(20%) + 跟风(15%) + 卡位(10%) + 反包(5%)
        ...
        return total, {'zong_long':.., 'zhong_jun':.., 'gen_feng':.., 'ka_wei':.., 'fan_bao':..}
```

### 4.2 节点判定引擎

```python
class NodeEngine:
    def determine(self, scores, tier_data, signals, prev_node, date) -> dict:
        # 硬判定：冰点/退潮/高潮
        # 软判定：结合prev_node + 题材阶段辅助
        main_stage = get_main_concept_stage(date)
        if prev_node == '启动' and main_stage in ('确认', '扩散') and JR_mid >= 0.30:
            node = '发酵'
        elif prev_node == '高潮' and main_stage == '亢奋' and Big_mid >= 2:
            node = '分歧'
        # ... 完整状态机
        forecast = self._forecast(node, tier_data)
        return {'node': node, 'prev_node': prev_node, 'forecast': forecast}
```

### 4.3 轮动监测引擎

```python
class RotationEngine:
    def detect_signals(self, date) -> list:
        signals = []
        old_main = get_prev_main_concept(date-1)
        if old_main and old_main['stage'] == '退潮':
            signals.append('OLD_MAIN_DECLINE')
        new_themes = get_themes_with_first_zt_surge(date)
        if new_themes:
            signals.append({'NEW_THEME_SEED': new_themes})
        # 高低切判定：老龙头放量下跌 + 新低位放量
        if old_main and old_main['space_leader']['close_chg'] < -3 and get_low_position_amount_surge(date) > 0:
            signals.append('HIGH_TO_LOW_SWITCH')
        return signals
```
